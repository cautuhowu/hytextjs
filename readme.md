# Hytext.js

**`Hytext.js`** is a lightweight JavaScript library for building web interfaces directly with the DOM.

Hytext.js provides a small layer over the native Web Platform, allowing HTML
elements to be created and composed using JavaScript while keeping direct
access to the underlying DOM APIs.

> Hytext.js does not attempt to replace the Web Platform.
> It provides a simple way to construct and work with it.

## Features

- Lightweight and dependency-free
- JavaScript-first web development
- Direct access to native DOM elements
- Nested element composition
- Event handlers through element attributes
- External CSS support
- Custom and hyphenated elements
- Works directly with browser APIs

**`Hytext.js`** là một JavaScript framework gọn nhẹ dùng để xây dựng giao diện web trực tiếp với DOM.

Hytext.js cung cấp một lớp mỏng bên trên nền tảng Web nguyên bản, cho phép các phần tử HTML được tạo và kết hợp bằng JavaScript trong khi vẫn giữ quyền truy cập trực tiếp vào các API DOM bên dưới.

> Hytext.js không có ý định thay thế Nền tảng Web.
> Nó cung cấp một cách đơn giản để xây dựng và làm việc với nền tảng đó.

## Tính năng

- Gọn nhẹ và không có thư viện phụ thuộc
- Xây dựng trình duyệt theo triết hướng JavaScript là trên hết
- Truy cập trực tiếp vào các phần tử DOM nguyên bản
- Lồng ghép và bố trí các phần tử linh hoạt
- Trình xử lý sự kiện thông qua thuộc tính của phần tử
- Hỗ trợ CSS bên ngoài
- Hỗ trợ các phần tử tùy chỉnh và có dấu gạch nối
- Hoạt động trực tiếp với các API của trình duyệt
